# 🐍 Descomplicando Python - Linux Tips

Bem-vindo ao meu repositório de estudos do curso **Descomplicando Python**, ministrado pela [Linux Tips](https://linuxtips.io/).

Este repositório serve como meu caderno digital, onde guardo anotações, exercícios, scripts de exemplo e os projetos desenvolvidos durante as aulas. O foco do curso é aprender Python com a mentalidade "Linux de ser", automatizando tarefas e entendendo como a linguagem interage com o sistema operacional.
